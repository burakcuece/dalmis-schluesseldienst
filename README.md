# DALMIS Mobiler Schlüsseldienst & Sicherheitstechnik

Statische, responsive Website für DALMIS aus Herten. Das Projekt funktioniert ohne Backend und ist für GitHub Pages vorbereitet.

## Dateien

- `index.html` – Startseite und Inhalte
- `style.css` – Mobile First Layout, Design und Animationen
- `script.js` – Navigation, FAQ Accordion und Scroll Reveals
- `assets/` – lokale SVG Grafiken und Social Preview
- `impressum.html` und `datenschutz.html` – vorbereitete rechtliche Seiten

## Vor der geschäftlichen Nutzung

Die vollständige ladungsfähige Anschrift und gegebenenfalls weitere gesetzliche Pflichtangaben müssen durch das Unternehmen ergänzt und rechtlich geprüft werden. Nicht bestätigte Aussagen wie 24/7 Erreichbarkeit, feste Anfahrtszeiten, Festpreise, Kartenzahlung, Bewertungen, Autoöffnungen oder Tresoröffnungen wurden bewusst nicht als Fakten veröffentlicht.

## GitHub Pages

Veröffentlichung über den Branch `main` und den Ordner `/ (root)`.
